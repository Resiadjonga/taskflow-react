# 🚀 TaskFlow

Application web moderne de gestion de tâches et de projets conçue pour optimiser la productivité quotidienne grâce à une interface fluide et un suivi en temps réel.

---

## 🎯 Objectifs du Projet

### Objectif Principal
Concevoir et développer une application web de gestion de tâches et de projets performante, intuitive et interactive, permettant aux utilisateurs d'optimiser leur organisation quotidienne.

### Objectifs Spécifiques
* Mettre en place un système d'authentification et de gestion des profils sécurisé.
* Développer un tableau de bord (*Dashboard*) centralisant les indicateurs clés de productivité.
* Assurer une gestion complète (CRUD) des projets et des tâches via des requêtes asynchrones connectées à une API locale.
* Intégrer des fonctionnalités de recherche multicritères et de filtrage instantané.

---

## 🛠️ Stack Technique & Outils

* **Frontend :** React.js, React Router DOM (pour la navigation SPA et ses hooks natifs : `useNavigate`, `useParams`, `useSearch`, etc.)
* **Style & UI :** CSS personnalisé, composants réactifs et modales interactives
* **Backend / Données :** JSON Server (API REST locale)
* **Outils de développement :** Git, GitHub, Visual Studio Code

---

## 🖥️ Aperçu des Interfaces

1. **Page de Connexion (`Connexion`) :** Authentification sécurisée avec validation des identifiants et redirection vers le tableau de bord.
2. **Tableau de Bord (`Dashboard`) :** Vue d'ensemble de la productivité, statistiques dynamiques et graphiques de progression.
3. **Page d'Inscription (`Inscription`) :** Création de compte avec vérification de l'unicité de l'e-mail.
4. **Paramètres (`Parametres`) :** Personnalisation du profil et mise à jour des informations utilisateur.
5. **Gestion des Projets (`Projets`) :** Administration complète du cycle de vie des projets (création, modification, suppression).
6. **Gestion des Tâches (`Taches`) :** Suivi détaillé, filtrage par statut (*À faire*, *En cours*, *Terminées*) et recherche en temps réel.
